    Sign-in & users · board

    Operators get only the boxes you tick. Admins can do everything, including this tab. The online board checks sign-in, taking control and user changes itself; the other boxes lock those parts of the dashboard.

    Failover

    Backup computer: open this same page there and sign in to board (or use Board code to paste the code and key). It stays on standby, mirrors what’s on air, and takes over if this one stops. Closing the dashboard in control hands over at once.

    Outputs: if every dashboard stops, DAK outputs keep pulling scores from ESPN and turning pages on their own, and they remember the last rundown, so a restart without internet still shows the last board. ESPN has a second address the board switches to if the first one fails.

    Screens online

    Stream Deck · Bitfocus Companion

    In Companion: add the Generic: HTTP Requests connection, then on each button add a GET action with one of these URLs. The dashboard in control carries the command out within a second. The Status URL returns JSON (page, paused, hidden, screens online) for button feedback. Keep the token private: anyone with these URLs can change pages.

    Ross DashBoard

    A ready-made custom panel with Prev / Next / Pause / First page / Hide buttons for each output, plus Freeze. It uses the control token above.

    In DashBoard: File > Open and pick the .grid file (or add it to a CustomPanel). The buttons send the same commands as the Stream Deck URLs, so you can also paste any URL into your own panel’s button task.

    Ross XPression & Daktronics data feed

    Live data for what each output is showing right now: page, title, and every game’s teams, ranks, scores, status, down & distance, network, possession, upset tag, logo URLs and the scoring-play text (standings pages list the teams in order). It updates whenever the dashboard in control changes page or a score changes.

    XPression: add a DataLinq source (XML) with the XML URL and a 1–2 second refresh, then link text fields with paths like /scoreboard/game[@slot='1']/away_score. The flat JSON URL has simple keys (g1_away_score, s3_name) for JSON sources. Daktronics: point a data feed (XML or JSON over HTTP) in your show-control software at the same URLs, or keep using the output links below as web content.

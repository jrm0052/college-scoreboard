    Who needs this page?

    • Running the show: nothing here. Everything for a show is on Control.
    • Stream Deck or Ross DashBoard buttons: see Control panels.
    • XPression or Daktronics graphics that pull the scores: see Graphics system data.
    • A backup computer, or moving to a new computer: see Backup computer.
    • Locking the board so people must sign in: see Sign-in & users (admins).

    Control panels: Stream Deck & Ross DashBoard

    1. Make a control token (once).
    2. Stream Deck (Bitfocus Companion): add the Generic: HTTP Requests connection. On each button, add a GET action and paste one of the button links.
    3. Ross DashBoard: , then File > Open it in DashBoard.
    Show button links

    The dashboard in control carries out each button press within a second. The Status link returns page, paused, hidden and screens online, for button feedback. Keep these links private: anyone with them can change pages.

    Graphics system data: XPression & Daktronics

    Each output has a live data link with what it’s showing right now: teams, ranks, scores, clock, down & distance, network, possession, upset tag, logos, scoring plays, player lines and standings.

    1. XPression: add a DataLinq XML source with the output’s XML link, refreshing every 1–2 seconds. Link text fields with paths like /scoreboard/game[@slot='1']/away_score.
    2. Daktronics: point an XML or JSON data feed in your show-control software at the link, or use the screen links as web content.

    On the backup computer, open this same page and sign in to board (or paste the board code & key below). It waits on standby, copies what’s on air, and takes over if this one stops. Venue screens keep running on their own even if every dashboard stops.
